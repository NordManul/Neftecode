# Примеры результатов

Производственные данные и большие результаты намеренно не хранятся в Git.
После запуска `python run.py demo` сюда можно скопировать обезличенные карточки
и JSON для показа на защите.

Минимальный комплект: четыре сценария из `outputs/demo/`, файлы валидации и
бэктеста, а также `outputs/dashboard.html`.
