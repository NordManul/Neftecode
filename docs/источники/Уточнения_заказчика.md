# Ответы организаторов на вопросы по постановке

Запись ответов, полученных по итогам встречи с организаторами (сентябрь 2026 г.). Значения из этих ответов приняты в проекте как
уточнение задания (тип значения `TASK`, источник `customer_clarification`).

1. Q21 — это содержание серы на выходе гидроочистки? Каковы единицы и что означает значение 307?

   Q21 — содержание серы на выходе, измеряется в ppm. 307 — это выброс.

2. Какие точные ограничения использовать для плотности и цетанового числа?

   1. ДТ с гидроочистки: плотность 820–845; цетановое число не нормируется.
   2. ДТ летнее товарное: плотность 820–845; цетановое число не менее 51.
   3. ДТ зимнее товарное: плотность 800–845; цетановое число не менее 49.

## Где используется

| Ответ | Реализация |
|---|---|
| Q21 — сера на выходе гидроочистки, ppm | `data_quality.q21_sulfur_valid`, фильтр серы (`mas/models/kalman.py`) |
| 307 — выброс | `data_quality.sentinel_values`: значение заменяется отсутствующим (`mas/prepare/quality_flags.py`) |
| Нормы плотности и цетанового числа | `spec.d15_range`, `spec.cetane_min`, `spec.winter.*`, сорт — `spec.product_grade` (`mas.common.commercial_norms`) |
