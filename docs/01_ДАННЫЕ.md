## 3. Аудит справочника тегов

Обнаружены противоречия между описанием тега и данными:

* 24-2000: `W7`, `F15`, `F17`, `F19`.
* АВТ: `F5`, `D10`, `F26`, `P44`, `P52`.

Механизм (`mas/prepare/tag_audit.py`): диапазон правдоподобия по категории величины, которая берётся из колонки
«Физическая величина» уточнённого справочника; перекрёстные проверки пар масса/объём (`F9/F15`, `F17/F26`,
`W10/F1` — заявленные справочником; `F9/F26`, `F19/F17` — выявленные по данным); смысловые проверки (доля
бензина от загрузки для тегов-расходов, W7 и F22). Категории всех 26 тегов 24-2000 совпали с ранее
восстановленными по проверенной таблице; реконструкция (`mas/io/reference.py::HO_TAGS_RECONSTRUCTED`) осталась
запасным вариантом на случай отсутствия файла.

Расхождения справочника и данных, которые не устранены уточнённым файлом и требуют пояснения владельца
тегов: `F15` (медиана 3400 м³/ч при массовом расходе сырья 220 т/ч, корреляция с `F9` 0.35), `F17` (данные
указывают на объёмный расход при описании «массовый»), `F19` (расход «бензина» 215 т/ч сопоставим с загрузкой
220 т/ч), `W7` (`W7/F22` = 1.6·10⁻⁵ т/нм³ против 4·10⁻⁴…2.5·10⁻³ т/нм³ для газа), `D10` (все значения 307),
`F5` и `F26` (отрицательные медианы расхода пара), `P44` (вакуум −0.9 в МПа физически невозможен, вероятна другая
единица), `P52` (перепад около нуля с отрицательным знаком). Теги, по которым принимаются решения (`T5`, `T6`, `F9`, `F32`,
`F65`, `Q21`), в этот список не входят.

## 4. Аналитические выводы

1. **Замкнутый контур управления.** Событийный анализ (`mas/calibrate/response.py`) даёт
   `βT ≈ −0.0098 /°C` и `βF ≈ 0.573` — заметно слабее литературной кинетики: на замкнутых данных
   чувствительность без физической модели недооценивается.
2. **Структура сигнала серы.** Совместная калибровка по анализам ЛИМС (обучающий период) раскладывает серу на
   медленную составляющую (τ ≈ 22.6 ч, СКО ≈ 1.15 мг/кг) и быструю (τ ≈ 2.4 ч, СКО ≈ 1.05 мг/кг); показание
   ПАК относится к моменту на 2 шага (20 мин) раньше отметки времени, запаздывание Q21 (40 мин) учтено
   в шуме измерения. Смещения приборов дрейфуют медленно; корреляция сырых показаний ПАК и Q21 умеренная (0.43),
   поэтому приборы дополняют друг друга.
3. **Погрешность лаборатории.** `sigma_lims ≈ 1.65` мг/кг — больше, чем запас между медианой (8.6 мг/кг)
   и нормой (10 мг/кг); поэтому единичный анализ ЛИМС не «истина», а ещё одно измерение с шумом, и состояние
   серы оценивается фильтром Калмана. Для T95 погрешность лаборатории `σ = 4.04 °C` подобрана по данным
   (раньше была задана константой 4.65 °C); покрытие 90 %-го интервала на отложенном периоде — 0.91.
4. **Формулы ВАК не проходят регламент**: 25 сверок «модель × точка отбора», пригодных 0. Лучшие R² на тесте:
   0.41 (`AVT6:350:T50`, AVT1), 0.30 (`24-2000:GODT:D15`, HT2, использует последний анализ ЛИМС) и 0.14
   (`AVT6:240-350:T50`, AVT3); по MAE после линейной калибровки ни одна формула не лучше «последнего анализа». В исходном
   листе «ВАК» формулы содержали опечатки (например, у `AVT6:350:T50` был другой набор коэффициентов); уточнённый
   файл их исправил, вывод не изменился. Входные значения тегов вне диапазона обучающего периода (расширенного на
   25 %) перед расчётом отбрасываются: единичные выбросы датчиков давали среднечасовые значения формул порядка 10⁵.
5. **Блендинг**: данных о компонентах, кроме ГО ДТ, присадках и запасах нет — смешение
   рассчитывается сценарно: свойства прочих компонентов и присадок заданы помеченными допущениями и
   настраиваются в конфигурации и в интерактивном просмотре.

Подробные числовые результаты — в `docs/03_РЕЗУЛЬТАТЫ.md`.
