# Состав системы и область применения

Числа — в `docs/03_РЕЗУЛЬТАТЫ.md` (формируется командой `python run.py docs`) и в `outputs/*`.

## 1. Цикл принятия решения

| Шаг | Реализация | Расположение |
|---|---|---|
| Связанная цепочка АВТ → гидроочистка → блендинг | Отбор F32 (АВТ) входит в модель серы и T95 продукта через `γ` и `b95`; блендинг — блок 8 карточки | `mas/models/kinetics.py`, `mas/models/t95.py`, `mas/agents/blending_agent.py` |
| 1. Снимок состояния | `DataAgent.snapshot` | `mas/agents/data_agent.py` |
| 2. Полнота, свежесть, согласованность данных | Список `Issue` трёх уровней; критические условия — `_issues()` | `mas/agents/data_agent.py` |
| 3. Текущее и прогнозное качество, риск | `QualityAgent.assess` | `mas/agents/quality_agent.py` |
| 4. Тяжесть режима, риск для оборудования | `ReliabilityAgent.assess` | `mas/agents/reliability_agent.py` |
| 5. Формирование допустимых вариантов | Сетка 105 вариантов (T5 × F9 × F32; загрузка не увеличивается) | `mas/agents/optimization_agent.py` |
| 6. Отсев недопустимых до ранжирования | `feasible` и `reject_reason` определяют допустимость независимо от порядка предпочтения | `Orchestrator.cycle` |
| 7. Сравнение по нескольким критериям | Порядок предпочтения без весов: больший выпуск ГО ДТ, затем меньший размер изменения режима; Парето-фронт по выпуску, запасу качества, тяжести режима и размеру изменения | `optimization_agent.py::_ranking`, `_pareto` |
| 8. Выбор и объяснение либо отказ | Четыре типа отказа, независимая повторная проверка | `Orchestrator._choose`, `_recheck` |
| Приоритет качества и ограничений над порядком предпочтения | Лексикографический порядок: критические данные → область модели → допустимость → порядок предпочтения (`test_high_rating_cannot_beat_quality_gate`) | `Orchestrator.cycle` |

## 2. Данные

| Правило | Реализация |
|---|---|
| Использование источников | `mas/io/*`; соответствие схем и тегов — `docs/01_ДАННЫЕ.md`, раздел 6 |
| Приоритет ЛИМС → ПАК → ВАК | Анализ ЛИМС входит в фильтр как контрольное измерение с погрешностью `σ_ЛИМС` и превосходит показания приборов по весу; результат, отклоняющийся от прогноза фильтра более чем на 5 стандартных отклонений, не принимается как измерение (16 из 1461 результатов серы, 1.1 %: явные ошибки вроде 107 и 120 мг/кг при соседних анализах 46 и 2 мг/кг, а также значения 17–23 мг/кг, которые могут быть реальными превышениями; в проверке качества оценок метки ЛИМС не отбрасываются). ВАК применяется только после регламента сверки (пригодных формул нет) |
| Отказы ПАК и Q21: заморозка (точное повторение показания), насыщение шкалы, отказ | `mas/prepare/quality_flags.py`; границы шкалы — `config/settings.yaml`, раздел `data_quality`; остальные пороги по данным — `cache/thresholds.json` |
| Синхронизация только по времени | `searchsorted` / `merge_asof` (`kalman.py`, `vak.py`, `data_agent.py`); сопоставления по номеру строки нет |
| Возраст анализа | `age_h`, `age_last_ok_h` в `Snapshot`; предельный возраст анализа — три медианных интервала между анализами в обучающем периоде (`calibrated.json`, `lims_age_limit_h`); учитывается в уровне доверия |
| Запаздывание отклика | Лаг F32 → T95 — 4 ч; результат ЛИМС доступен с момента отбора (времени выдачи в данных нет), оценка перед анализом строится по состоянию до него; задержки анализаторов — параметры фильтра |
| Единицы измерения | Фиксированный словарь `mas/io/lims.py::UNITS`, конфликты — в `lims_units.csv` |
| Смысл тега | Справочник и аудит противоречий (`mas/prepare/tag_audit.py`) |

## 3. Агенты

| Агент | Ответственность | Результат |
|---|---|---|
| DataAgent | снимок, флаги качества, аномалии | `Snapshot` |
| QualityAgent | прогноз серы и T95, риск, доверие | `QualityAssessment` |
| ReliabilityAgent | индекс тяжести, факторы, ограничения | `ReliabilityAssessment` |
| OptimizationAgent | допустимые варианты и метрики | `CandidateSet` |
| BlendingAgent | режимы `product_only`, `scenario`, `manual`; доли компонентов, присадки, спецификация смеси | план смешения |
| Orchestrator | решение, альтернативы, отказ | `Recommendation` |

Агенты обмениваются сообщениями только через `MessageBus` (`mas/bus.py`); журнал шины входит в каждую карточку.

## 4. Управляющие воздействия

| Тема | Реализация |
|---|---|
| Набор параметров | T5, F9, F32 (обоснование — `docs/02_ОБОСНОВАНИЕ.md`) |
| Участки | F32 — рычаг АВТ; T5 и F9 — гидроочистка; ГСС — ограничение, не рычаг; блендинг — сценарный расчёт с настраиваемыми компонентами и присадками |
| Границы | Регламента установки в материалах нет: коридоры p1–p99 обучающего периода (задание, «правило границ») и сетка изменений `decision_vars`; источник указан в `src` |
| Сера ≤ 10 мг/кг | Шанс-ограничение по смеси 27 членов ансамбля: откалиброванная вероятность превышения не выше `risk_alpha` = 5 % (`mas/calibrate/probability.py`) |
| Остальные показатели | T95 — правило «не навреди» и эскалация; D15 — контроль по свежим ЛИМС с эскалацией; цетановое число — норма только у товарного ДТ (проверка смеси); ПТФ не проверяется: норма в материалах проекта не задана |
| Сумма долей смеси = 100 % | `BlendingAgent` и повторная проверка в `Orchestrator._recheck` |
| Пределы оборудования | `ReliabilityAgent.evaluate`: `bounds`, `step_limits`; верхняя граница T5 — 99-й перцентиль обучающего периода |

## 5. Карточка оператора (8 блоков)

1. Время и состояние. 2. Проблема / риск. 3. Предлагаемое действие. 4. Ожидаемый эффект.
5. Проверка ограничений. 6. Уверенность. 7. Объяснение. 8. Блендинг.

Формируются в `Orchestrator._blocks` (`mas/agents/orchestrator.py`), отображаются в `mas/report/card.py`.

| Тема | Реализация |

| Парето-анализ | `OptimizationAgent._pareto`, список альтернатив |

## 8. Ограничения

| Ограничение | Причина | Принятая мера |
|---|---|---|
| Расхождения уточнённого справочника тегов и данных | Часть описаний не согласуется с показаниями (подробности — `docs/01_ДАННЫЕ.md`, раздел 4) | Аудит выявляет противоречия: `F15, F17` (24-2000), `F5, D10, F26` (АВТ). Теги, используемые в решениях, в списке отсутствуют. Исходный раздел 24-2000 (со сдвигом описаний) заменён уточнённым файлом, реконструкция осталась запасным вариантом |
| Формулы ВАК не согласуются с данными | В исходном листе «ВАК» часть формул содержала опечатки (скобки, знаки, коэффициенты); уточнённый файл `формулы_ВАК.xlsx` их исправил, но и с ним ни одна формула не воспроизводит лабораторные значения (лучший R² на тесте 0.41 при худшей MAE, чем у «последнего анализа») | Регламент выполнен по уточнённому файлу: 17 формул, 25 сверок «модель × точка отбора», пригодных нет; контрольной величиной остаётся ЛИМС |
| Блендинг по компонентам не рассчитывается | В материалах проекта нет данных о компонентах 2–3, присадках, запасах и величине партии | По умолчанию режим `product_only`: товарное ДТ равно ГО ДТ и проверяется по нормам сорта (сера, T95, цетановое число, плотность). Режимы `scenario` и `manual` работают по данным, внесённым пользователем в `blending` (`config/settings.yaml`, формат — `tests/blending_data.py`) |
| T95 управляется слабо | Связь с F32 подтверждена на обучающем периоде (наклон ≈ 0.15), но структурно слаба и нестабильна на тесте | Правило «не навреди» и эскалация технологу |
| Прогноз превышения серы через 4 ч не лучше климатологии (AUC 0.55, Brier 0.169 против 0.140) | Замкнутый контур: оператор компенсирует возмущения до попадания в данные; быстрые колебания серы не предсказываются на часы вперёд; погрешность лаборатории порядка запаса до нормы | Решения принимаются по текущей оценке серы (Brier 0.126, лучше климатологии); корректирующее действие назначается при вероятности превышения выше 1/2 (нейтральная граница, нет стоимостных данных); при неопределённости — отказ |
| Преимущество фильтра серы над средним двух приборов не подтверждено | Данных после 2026-08-08 нет; на внутренней проверке (подбор по 2023, оценка по 2024) MAE фильтра 1.49, среднего двух приборов 1.33 мг/кг, AUC 0.77 и 0.77, Brier не лучше климатологии | Оценка серы остаётся фильтром (интервалы неопределённости, задержка анализаторов, пропуск прибора); порог действия консервативен; результаты отложенного периода — оценка сверху (`docs/02`, раздел 2.4) |
| Вероятности превышения T95 завышены в верхней области | Верхний хвост распределения T95 тоньше нормального (процесс управляется): при расчётной вероятности выше 1/2 превышение наблюдается в 17.6 % случаев; превышений на обучающем периоде 1.1 % | Правило «не навреди» остаётся консервативным; интервал T95 откалиброван (покрытие 0.91) |
| Часть калибруемых величин (`b95`, слабая `βT`, `γ`) статистически чувствительна к окну и детрендированию | Оценка по данным замкнутого контура | Параметры не подбирались под желаемый результат; неопределённость отражена ансамблем |
