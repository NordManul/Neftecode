## Ограничения для защиты

Компоненты блендинга и присадки не были предоставлены. Поэтому промышленный
режим по умолчанию — `product_only`, а значения сценарных компонентов являются
допущениями и не выдаются как подтверждённая промышленная рецептура.
Формулы ВАК используются только после регламентной сверки; при непригодной
формуле контрольным фактом остаётся ЛИМС.
