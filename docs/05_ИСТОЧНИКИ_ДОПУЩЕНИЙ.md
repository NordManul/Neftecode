# Источники допущений

У каждого допущения из `config/settings.yaml` указан источник (поле `ref`, реестр — `config/references.yaml`). Если официального источника нет, это указано явно, а значение не выдаётся за нормативное.

Типы источников: **нормативный документ**; **литература (не норматив)**; **данные проекта**; **официального источника нет**.

## Использованные источники

* **нормативный документ** — [ТР ТС 013/2011 «О требованиях к автомобильному и авиационному бензину, дизельному и судовому топливу, топливу для реактивных двигателей и мазуту»](https://protect.gost.ru/tr/details/dfbf7ee2-f248-48c0-ad2b-202191e351bb). массовая доля серы в дизельном топливе экологического класса 5 - не более 10 мг/кг
* **нормативный документ** — [ГОСТ ISO 3405-2013 (ISO 3405:2011) «Нефтепродукты. Определение фракционного состава при атмосферном давлении»](http://docs.cntd.ru/document/1200108426). метод для лёгких и средних дистиллятов с температурой конца кипения ниже 400 °C, ручной и автоматический аппараты. Прецизионность для дизельного топлива (группа 4), T95 = температура при 95 % об. отгона: автоматический аппарат (табл. 9, T в диапазоне 260-340 °C) повторяемость r = 0,015(T - 140), воспроизводимость R = 0,04227(T - 140); ручной аппарат (табл. 7) r = 0,41·ΔC/ΔV + 1,0, R = 1,33·ΔC/ΔV + 1,8, где ΔC/ΔV - наклон кривой разгонки, °C на % об. Различие двух результатов превышает r или R только в одном случае из двадцати. Регистрация: 0,5 °C для ручного и 0,1 °C для автоматического метода (разд. 12)
* **нормативный документ** — [ГОСТ ISO 20846-2016 (ISO 20846:2011) «Нефтепродукты жидкие. Определение содержания серы в автомобильных топливах. Метод ультрафиолетовой флуоресценции»](https://meganorm.ru/Index2/1/4293738/4293738758.htm). область применения 3-500 мг/кг; результат - среднее трёх определений, записывается с точностью 0,1 мг/кг при значении менее 60 мг/кг (разд. 10-11). Прецизионность для дизельного топлива, 3-60 мг/кг (табл. 2-3): повторяемость r = 0,0553X + 0,55, воспроизводимость R = 0,1120X + 1,12 (X - среднее результатов, мг/кг); на 10 мг/кг r = 1,1, R = 2,2 мг/кг. Различие двух результатов может превысить r или R только в одном случае из двадцати (r = 2,77σ)
* **нормативный документ** — [ГОСТ ISO 20884-2016 (ISO 20884:2011) «Нефтепродукты жидкие. Определение содержания серы в автомобильных топливах. Метод рентгенофлуоресцентной спектрометрии с дисперсией по длине волны»](http://docs.cntd.ru/document/551515942). область применения 5-500 мг/кг; результат записывается с точностью 0,1 мг/кг при значении 5-99 мг/кг (разд. 11). Прецизионность (табл. 4), 5-60 мг/кг: повторяемость r = 1,7 + 0,0248X, воспроизводимость R = 1,9 + 0,1201X (X - среднее результатов, мг/кг); на 10 мг/кг r = 1,9, R = 3,1 мг/кг
* **нормативный документ** — [ГОСТ Р 51947-2002 «Нефть и нефтепродукты. Определение серы методом энергодисперсионной рентгенофлуоресцентной спектрометрии»](https://protect.gost.ru/gost/details/32ddba4b-28ac-43cf-adfe-3ec694783054). область применения: массовая доля серы от 0,0150 % до 5,00 % (150-50000 мг/кг) в дизельном топливе, нефти, керосине, остатках, основах масел, реактивных топливах, неэтилированном бензине. Применима к сере в сырье (ЛИМС ГО т.1, Mass.Sulfur, медиана 0,95 %); сера продукта на уровне 10 мг/кг лежит ниже нижней границы, метод к ней не применим. Метод лаборатории в данных не указан
* **нормативный документ** — [ГОСТ 32511-2013 (EN 590:2009) «Топливо дизельное ЕВРО.
